# character2.png — 점프와 추가 스킬

원본 디자인 참고: 프로젝트 루트의 `character1.png`.
결과 이미지: 프로젝트 루트의 `character2.png`.
제작 방식: 내장 이미지 생성 도구, 원본 이미지를 디자인/스타일 참고 자료로 사용.

4열 × 4행의 투명 배경 PNG입니다. 각 행은 왼쪽에서 오른쪽으로 재생합니다.

| 행 (위에서부터) | 동작 | 4프레임 순서 |
| --- | --- | --- |
| 1 | 점프 | 준비 → 도약 → 공중 → 착지 |
| 2 | 돌진 찌르기 | 준비 → 전진 → 찌르기 → 회수 |
| 3 | 올려베기 | 낮은 준비 → 상승 베기 → 마무리 → 회수 |
| 4 | 공중 내려찍기 | 공중 준비 → 하강 베기 → 충격 → 회수 |

프레임은 이미지 너비와 높이를 각각 4등분해 자릅니다. 소수점 경계는 반올림한 정수 좌표를 사용하세요. pico2d의 소스 y는 `image.h - bottom`입니다.

`character.py`에서 프레임별 피벗을 보정하고 점프 높이와 이동 거리를 처리합니다.

- J: 점프 (공중에서 좌우 이동 가능)
- I: 돌진 찌르기
- O: 올려베기
- K: 공중 내려찍기 (지상에서는 짧게 도약 후 공격, 점프 중에는 즉시 하강)
- U: 기존 검 공격
- 방향키 또는 A/D: 이동

공격은 애니메이션과 캐릭터 이동을 처리합니다. 적과 피해 판정은 아직 구현되어 있지 않습니다.

정확한 생성 프롬프트는 `character2_prompt.txt`에 저장했습니다.
