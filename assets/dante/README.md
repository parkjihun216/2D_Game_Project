# 단테 캐릭터 리소스

내장 이미지 생성 도구로 새로 만든 Devil May Cry 단테 팬아트 스프라이트 시트입니다.

- 파일: `dante_spritesheet.png`
- 구성: 4열 × 4행, 총 16프레임. 왼쪽에서 오른쪽 순서.
- 1행: 대기 / 2행: 달리기 / 3행: 검 공격 / 4행: 권총 사격
- 배경: 알파 투명 PNG
- 실제 해상도: 1254 × 1254. 셀 경계는 x/y 모두 `[0, 314, 627, 941, 1254]` 픽셀입니다.
- 기존 `character.png`와 게임 코드는 변경하지 않았습니다.

위의 정수 경계로 프레임을 자르세요. pico2d의 clip_draw는 왼쪽 아래가 원점이므로 소스 y는 `image.h - bottom`이며, 잘라낼 폭과 높이는 `right - left`, `bottom - top`입니다. 생성 이미지의 자세별 발 위치에는 차이가 있어, 재생 시 프레임별 피벗 보정이 필요할 수 있습니다. 기존 character.py의 프레임 좌표와는 호환되지 않습니다.
